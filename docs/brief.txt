Тестовое задание на позицию
«Технический специалист»


Контекст. Мы - аутрич-агентство, и у нас есть собственная внутренняя платформа: Next.js + TypeScript + PostgreSQL, фоновые воркеры, парсеры, интеграции с внешними API. Платформу мы развиваем через AI-инструменты (Claude Code, Cursor) - и тебе предстоит делать то же самое. Это задание повторяет наши реальные задачи: интеграция, данные, багфикс, доведение до работающего результата.

Пользоваться AI не просто можно - нужно. 


Задания
Задача 1: Выгрузка → Postgres
	 Прилагаем архив data_pack.zip — в нём выгрузка из нашего внутреннего API: файлы page_001.json … page_020.json, ~1000 компаний
   (название, категория, город, адрес, рейтинг, число отзывов, сайт, телефон). Формат - как есть, без документации: разберись в структуре сам.


* Забери все записи из всех страниц
* Спроектируй схему и загрузи данные в PostgreSQL (Docker или бесплатный Supabase): дедупликация, индексы.
*  Приложи 3 SQL-запроса: топ-5 категорий по числу компаний; средний рейтинг по городам среди компаний с 10+ отзывами; доля компаний с
сайтом по категориям.
* Результат: репозиторий со скриптом загрузки, schema.sql, queries.sql и README с командой запуска.
	Инструмент
Claude Code / Cursor / Codex / Kimi Code — любой.
	Задача 2: Мини-фича с доказательством работы
	Небольшая страница на Next.js (App Router) поверх базы из задачи 1:
   * Маршрут /companies: таблица компаний из Postgres с поиском по названию и фильтром по городу.
   * Данные тянуть серверно (Route Handler или Server Component), никаких секретов в репозитории — только .env.example.
   * Приложи доказательство, что всё работает: скриншоты страницы + 3–5 предложений, как проверял сам (что тыкал, что ломалось в процессе).  Пункт «как проверял» обязателен.
	Инструмент
Claude Code / Cursor / Codex / Kimi code
	Задача 3: Данные с сюрпризом
	В том же архиве лежит review.csv - якобы свежая выгрузка для той же базы. Загрузи её скриптом и дай короткий отчёт по данным. Но будь начеку: вдруг мы что-то перепутали…
   * Всё странное, что заметишь, перечисли в ANOMALIES.md - что именно не так и как ты это обнаружил.
	Инструмент
Claude Code / Cursor / Codex / Kimi code любой AI
	



Задача 4: Вайбкод/LLM-стек
	 Напиши своими словами, без ИИ. Чем больше конкретики, тем лучше.
   * Твой выбор IDE и LLM моделей сейчас и как он менялся последние полгода.
   * Сколько и каких подписок в месяц тебе хватает для полноценной работы.
   * Как сравниваешь две новые модели или инструмента - по ощущениям или на одинаковом наборе задач? 
   * Какие тесты ты потребуешь для новой функции? 
   * Какие разрешения ты дашь coding-агенту, имеющему доступ к терминалу и базе? 
   * Пишешь ли ты автоматические тесты и включаешь ли их в CI/CD? Какие проверки должны обязательно пройти перед слиянием и деплоем.
