# PROOF — как проверял

## Итерация 1

1. Поднял Postgres через `docker compose up -d` (порт `5433`).
2. Прогнал `scripts/load_companies.py`: 1000 JSON-строк → 994 уникальных id.
3. Упал upsert из-за лишнего столбца `updated_at` в INSERT — поправил, перезапустил.
4. Прогнал `scripts/load_reviews.py`, получил `ANOMALIES.md`.
5. Выполнил `queries.sql` — три запроса вернули строки.
6. Собрал Next.js `/companies`, поднял `npm run dev`, открыл страницу в браузере.

Что ломалось:

- Docker daemon сначала не был запущен — стартовал Docker Desktop.
- В zsh переменная `status` read-only — переименовал в `health`.
- Детектор mojibake ловил нормальные города вроде «Ростов-на-Дону» — ложное срабатывание.
